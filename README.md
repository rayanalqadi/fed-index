# مؤشر الفيدرالي (Fed Index) - الموقع الحي

موقع Next.js يعرض توقع قرار الفيدرالي القادم، ويحدّث نفسه تلقائيًا كل يوم
بمقارنة أحدث بيانات FRED مع آخر توقع محفوظ.

## خطوات النشر على Vercel

### 1. رفع المشروع
ارفع هذا المجلد كمستودع GitHub جديد، ثم استورده في Vercel (Add New → Project
→ Import Git Repository).

### 2. إضافة قاعدة بيانات Vercel KV
من داخل مشروعك في Vercel: **Storage** → **Create Database** → اختر **KV**
→ اربطها بالمشروع. هذا يضيف متغيرات البيئة اللازمة (`KV_REST_API_URL`
و`KV_REST_API_TOKEN` وغيرها) تلقائيًا.

### 3. إضافة متغيرات البيئة (Settings → Environment Variables)
| المتغير | القيمة |
|---|---|
| `FRED_API_KEY` | مفتاح FRED الخاص بك (من حسابك في fred.stlouisfed.org) |
| `CRON_SECRET` | أي نص سري عشوائي طويل تختاره أنت (يحمي مسار التحديث) |

### 4. إعادة النشر (Redeploy)
بعد إضافة المتغيرات، أعد النشر مرة عشان تُطبَّق.

### 5. أول تشغيل يدوي (اختياري لتجربة فورية)
افتح في المتصفح:
```
https://your-domain.vercel.app/api/cron/update
```
مع إضافة الترويسة `Authorization: Bearer <CRON_SECRET>` — أو ببساطة انتظر
أول تشغيل تلقائي (Vercel Cron مضبوط على `vercel.json` ليعمل يوميًا الساعة
6:00 صباحًا UTC).

## كيف يشتغل التحديث التلقائي
1. Vercel Cron يستدعي `/api/cron/update` يوميًا
2. المسار يجلب أحدث بيانات FEDFUNDS وUNRATE وPCEPILFE وPAYEMS من FRED مباشرة
3. يقارن أحدث تاريخ بيانات بالمخزَّن سابقًا - لو ما فيه جديد، يتوقف بدون إعادة حساب
4. لو فيه بيانات جديدة، يشغّل نموذج v4 (`lib/predictor.js`) ويحسب توقعًا جديدًا
5. يخزّن النتيجة في Vercel KV
6. الصفحة الرئيسية (`app/page.js`) تقرأ آخر نتيجة مخزّنة وتعرضها كجملة واحدة

## قيد يدوي مهم
ملف `app/api/cron/update/route.js` فيه ثابت `KNOWN_DECISION_HISTORY` — قائمة
آخر قرارات FOMC **الفعلية المؤكدة** (hold/hike/cut). هذي لازم تُحدَّث يدويًا
بعد كل اجتماع فعلي (كل ~6 أسابيع)، لأنها معلومة "وقع فعلاً" وليست بيانات
اقتصادية خام تقدر تُجلب تلقائيًا من FRED. لو ما حدّثتها، النموذج بيستمر
يحسب بناءً على آخر حالة دورة معروفة له (مو خطأ فادح غالبًا، بس أدق لو حدّثتها).

## الملفات
- `lib/fred.js` — جلب البيانات من FRED API
- `lib/predictor.js` — نموذج v4 (نسخة JS مطابقة لـ `predictors.py` بايثون، دقة 90.2% على 51 اجتماع تاريخي)
- `app/api/cron/update/route.js` — مهمة التحديث التلقائي
- `app/page.js` — صفحة العرض بجملة واحدة
- `vercel.json` — جدولة Cron (يوميًا 6:00 صباحًا UTC)
